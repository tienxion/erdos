# Erdős problem 97

[Problem statement](https://www.erdosproblems.com/97) · [Research status](research-notes.md)

No full proof or counterexample has been obtained. This folder contains geometric restrictions, combinatorial checks, and numerical searches. Abstract incidence graphs and approximate numerical configurations are not counterexamples to the problem.
