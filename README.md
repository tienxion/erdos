## Using the repository

Each `erdos<number>/` folder contains its own notes and available code and data. Start with its README for the main proof, references, and limitations. Finite computations and numerical searches have the scope stated in their notes; they are not proofs of the unrestricted problems.

The [561 manuscript archive](erdos561/submitted/v1/) preserves the previously compiled, submitted PDF, its source, and its checksum. The [1163 submitted write-up](erdos1163/proof.md) is formatted for GitHub; its original source remains at [proof_site/proof.md](erdos1163/proof_site/proof.md). Earlier and subsequent investigations remain available as individual Markdown files.

Original-paper links are retained in the literature notes. Local environments, downloaded papers, temporary builds, and compiled executables are omitted. Dependencies and reproduction instructions are recorded with the relevant experiments.

## Attribution and review

The research records disclose AI assistance from OpenAI Codex and identify the published results on which the arguments rely. Informal proof reviews, finite checks, human review, and external peer review are distinguished in the individual notes. Novelty and priority remain subject to the limitations recorded there.
